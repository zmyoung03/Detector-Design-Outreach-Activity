This repository houses the 3D printing files and supplementary documentation for my 2026 MSc project, working title DIY Detectors.

DIY Detectors is a particle and nuclear physics (PNP) outreach activity that revolves around participants modeling, building, and testing their own particle detectors.

Including introduction and conclusion presentations, the activity should run for 45-60 minutes. It's made for participants with minimal PNP experience, but can be enjoyed by anyone.
