This folder contains all supplementary documentation for the project, including:
- An instruction manual for the person(s) running the activity
- A worksheet that can be used during the activity
- An example presentation that can be given at the beginning/end of the activity
- Python code for running the electronic sensors used in the activity
- Suggested questions for getting feedback/participant evaluation of the activity (in the instruction manual)
- An example circuit diagram to help wire the sensors to a microcontroller
